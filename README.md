# Majestic

Модульный GUI-хаб для Roblox, реализованный в двух версиях на разных UI-библиотеках — **Fluent** и **Luna Interface Suite**. Обе версии объединяют несколько независимых игровых модификаций в одном окне с вкладками.

---

## 📌 Описание

Majestic — пользовательский интерфейс (хаб), который собирает разрозненные игровые модификации в одном окне вместо подключения каждого скрипта отдельно. В репозитории представлены две параллельные реализации одного и того же функционала:

| Файл | UI-библиотека | Особенность |
|---|---|---|
| `Majestic(Fluent).lua` | [Fluent](https://github.com/dawid-scripts/Fluent) | Более современный UI, встроенное сохранение конфигов (`SaveManager`, `InterfaceManager`), вкладка **Settings** |
| `Majestic(LunaUI).lua` | Luna Interface Suite | Классический вариант с системой ключей (`KeySystem`) и кастомным лого |

## ⚙️ Технологии

- **Lua** (диалект Luau, среда выполнения Roblox)
- Подключение внешних UI-библиотек через `loadstring` + `HttpGet`
- Работа с сервисами Roblox API: `Players`, `RunService`, `Workspace`, `Drawing`

## 🧩 Функциональность

Функционал одинаков в обеих версиях и разбит на независимые вкладки:

- **Main** — загрузчик сторонних утилит: административная консоль (Infinite Yield), скрипт невидимости, защита от AFK-кика
- **Movement** — слайдер скорости персонажа (WalkSpeed 16–200) с автоматическим восстановлением значения после респауна через подписку на `CharacterAdded`
- **Visual** — ESP: подсветка всех игроков сквозь стены (`Highlight`-инстансы) с выбором цвета через колорпикер
- **Combat** — автоприцеливание: поиск ближайшей головы игрока в заданном радиусе экрана, индикатор зоны прицеливания (`Drawing.new("Circle")`), настройка плавности наведения камеры и фильтр «не целиться в союзников» (TeamCheck)
- **Settings** *(только в версии Fluent)* — сохранение и загрузка пользовательских конфигураций через `SaveManager`/`InterfaceManager`

## 🏗️ Архитектура

```
Window (Fluent:CreateWindow / Luna:CreateWindow)
├── Tab: Main       → загрузка внешних скриптов через HttpGet
├── Tab: Movement   → цикл в RunService.Heartbeat, слайдер скорости
├── Tab: Visual     → подписка на PlayerAdded/CharacterAdded, ESP-подсветка
├── Tab: Combat     → RenderStepped-цикл, поиск цели по экранным координатам
└── Tab: Settings   → SaveManager/InterfaceManager (только Fluent-версия)
```

Каждый модуль подписывается на нужные события Roblox (`Heartbeat`, `RenderStepped`, `PlayerAdded`) и работает независимо от остальных вкладок, что позволяет включать/выключать функции по отдельности.

## 💡 Что демонстрирует проект

- Умение работать с разными UI-фреймворками поверх одной и той же бизнес-логики (портирование функционала между Fluent и Luna)
- Работу с событийной моделью Roblox (`RunService`, сигналы `Connect`)
- Векторную математику и работу с камерой/вьюпортом (`WorldToViewportPoint`)
- Управление жизненным циклом объектов (создание/удаление `Highlight`, отписка от событий)
- Работу с сохранением пользовательских настроек (config persistence через `SaveManager`)

## ⚠️ Примечание

Скрипты предназначены для запуска через сторонние среды выполнения (executors) и модифицируют поведение игрового клиента — это нарушает условия использования Roblox. Используйте на свой страх и риск.
